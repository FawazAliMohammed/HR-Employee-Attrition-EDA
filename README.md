# HR Employee Attrition — Clean, Explore & Engineer

## Project Overview

This project analyzes an HR Employee Attrition dataset to understand
factors that may be related to employees leaving a company.

## Tasks Completed

- Loaded and inspected the dataset
- Checked missing values
- Checked duplicate records
- Inspected potential outliers
- Performed exploratory data analysis
- Created multiple visualizations
- Compared employee groups
- Created new features
- Summarized five key findings

## Visualizations

The notebook contains:

- Employee attrition count plot
- Age distribution histogram
- Monthly income boxplot
- Correlation heatmap
- Overtime and attrition comparison
- Job satisfaction and attrition comparison

## Feature Engineering

Three new features were created:

1. CompanyExperienceRatio
2. PromotionRatio
3. IncomePerJobLevel
